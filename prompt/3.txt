Isi dari planning ny adalah sebegai berikut:

Buatkan tabel sessions:
- id integer auto increment primary key
- token varchar(255) not null (isinya uuid untuk token user yang login)
- user_id integer (FK ke tabel users)
- created_at timestamp default current_timestamp

Buatkan API untuk login user

Endpoint : POST /api/auth/login
Request Body : 
{
    "email": "may@babas.com",
    "password": "rahasia"
}

Response Body (Success):

{
    status: true,
    message: "Login successfully",
    data: {
		"token": "2142-124-124saf-safas"
    }
}

Response Body (Error):
{
  "status": false,
  "message": "Email atau password salah"
}
